# BeniTTS Updates (public downloads only)

This repository is **public on purpose** so the BeniTTS_VTS Android app can fetch update packs without opening the private source repo.

## What is here

- `catalog.json` — version index the app reads
- Release assets — modular zips such as `vts-koochik-*.zip` (offline speech recognition)

## What is NOT here

- App APK / source code
- Signing keys, tokens, CI secrets
- Private project files from Beni-Repository-HUB

The main product repo stays private.
